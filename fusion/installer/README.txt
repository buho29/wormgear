Worm and wheel (WormGear) - Fusion 360 add-in
=============================================

Generates a parametric worm and worm wheel, designed to be 3D printed
without supports.

Install (Windows)
-----------------
1. Unzip the whole zip into any folder.
2. Double-click instalar.bat.
3. In Fusion 360: Utilities > Add-Ins (Shift+S) > WormGear > Run,
   and tick "Run on Startup" so it always starts.

The button is in SOLID > CREATE > Worm and wheel, and in ASSEMBLE > CREATE
in assembly designs. The add-in is in Spanish if Fusion is in Spanish,
and in English otherwise.

To update to a new version, run its instalar.bat: the last dialog values
are kept. If Fusion is open, stop the add-in and run it again.

Uninstall
---------
Stop the add-in in Fusion and double-click desinstalar.bat.

Mac
---
Copy the WormGear folder to
~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/
